# 微信外壳（可切换界面）实现方案

> 状态：**待你确认**（确认后才写码）。
> 范围：整套应用骨架换成微信式四页底栏；现有"侧栏 + 聊天"骨架保留为默认，可随时切回。
> 不做：朋友圈内容（本期只放空壳）、群聊（只留分组位）、未读红点、长按/左滑手势。

---

## 0. 三件套

| 项 | 内容 |
|---|---|
| 用户能感知的一句话变化 | 设置 → 主题商城 → **界面**，多一个「微信」；切过去整个 App 变成微信骨架：底部四页（微信 / 通讯录 / 朋友圈 / 我），点会话进入聊天页，返回退回列表 |
| 开关 | 主题商城新增第 4 组「**界面**」：经典 / 微信（`html[data-gaia-layout]` + `localStorage['gaia:theme-layout']`） |
| 默认值 | **经典**（不切 = 现在这个样子，零变化） |

## 1. 目标与验收标准

### 1.1 结构

```
[微信]          [通讯录]         [朋友圈]        [我]
  │                │               │              │
  ├ 会话列表        ├ 添加联系人      └ 空壳页        ├ 用户头像卡
  │  （按时间分组）  ├ 群聊（空）                     ├ 设置
  └ 点一下           └ 角色卡列表                      ├ 余额
     ↓                                                  ├ 服务商
  聊天页（可返回）                                       ├ 主题商城
                                                        ├ 记忆
                                                        ├ 诊断
                                                        ├ 数据管理
                                                        └ 公告
```

### 1.2 验收标准（做的时候照这个逐条验）

1. 默认打开 = 经典壳，和现在完全一样（含桌面宽屏）。
2. 主题商城出现第 4 组「界面」，选「微信」立即变壳，选「经典」立即回去；刷新后保持。
3. 微信壳底栏四页可切换，当前页高亮；底栏不遮内容（列表/聊天都能滚到底）。
4. 第 1 页「微信」= 现有全部会话，按时间分组；点一条进入聊天页；聊天页左上角返回回到列表（**返回后列表滚动位置不丢**）。
5. 第 2 页「通讯录」= 角色卡列表；最上面「添加联系人」点开 = 现有"新建角色"编辑器；点某个角色进入**该角色的最近一条会话**（没有则新建一条并进入）。
6.「群聊」分组位存在，点开提示"还没做"（与 §10 群组设计对应，不实现功能）。
7. 第 3 页「朋友圈」= 空壳占位（一句"朋友圈还没做"+ 返回图标），不请求网络。
8. 第 4 页「我」= 用户头像+昵称（点开可改，沿用现有档案编辑）+ 上表 9 项入口，每项点开的就是现在那个页面（设置/余额/服务商/主题商城/记忆/诊断/数据管理/公告）。
9. 安卓返回键：聊天页 → 回列表；列表页 → 不消费（交给原生退到桌面）；各弹层仍按原优先级（设置 70 / 服务商 75 / 角色 60 / 主题 60 / 记忆 55 / 余额 50 / 搜索 30）先关。
10. 微信壳任一处渲染报错 → 只这一次自动回退经典壳（并 toast 一句"界面已切回经典"），不出现全屏空白。

## 2. 四个 tab 的内容与数据来源

| tab | 内容 | 数据/组件来源 | 性质 |
|---|---|---|---|
| 微信 | 会话列表（分组、标题、时间、角色圆标） | `services/chat/store`（sessions / newChat / selectSession）+ `sessionGroups` + 自画行 | 复用数据，重画行 |
| 通讯录 | 角色卡列表 + 添加联系人 + 群聊空位 | `roles` 积木（列表页与新建编辑器现成）| 通过新槽位注入 |
| 朋友圈 | 空壳 | — | 新写（占位） |
| 我 | 9 项入口 | `profile`/`account`/`providers`/`theme`/`memory`/`diagnostics`/`intro`/`settings` 各注入一行 | 通过新槽位注入 |

> **为什么不直接搬 `Sider`**：`Sider` 自带"收起侧栏"按钮、蓝色新建按钮、底部"设置"按钮，微信壳里这三样都要换位置/换样子；而 `SessionItem` 的样式是 DeepSeek 风格，CSS module 类名拿不到。所以第 1 页**只复用数据层**（store + 分组函数），行自己画（微信行：圆头像 + 标题 + 时间；我们没有"最后一条消息预览"字段，第二行显示角色名）。

## 3. 架构落法（怎么切壳而不撕碎积木）

### 3.1 平台层（L0）

- `platform/runtime.ts` 新增 `AppLayout = 'classic' | 'wechat'`、`useLayout`（zustand，同 `useUser` 的写法）、`setLayout`、`currentLayout`。
- 新增槽位（`platform/types.ts`）：

| 槽位 | 模式 | payload | 谁用 |
|---|---|---|---|
| `app.root` | replace | `{}` | `shell` 积木接管整屏 |
| `session.header` | replace | `{ title }` | `shell` 用自己的微信顶栏（返回+标题+…） |
| `shell.contacts` | replace | `{}` | `roles` 注入角色卡列表 |
| `shell.me.item` | append | `{}` | 各积木注入「我」页入口行 |

### 3.2 新积木 `features/shell`

- `defineBlock({ id: 'shell', order: -200, flags: { shell: true } })`
- 文件：`AppShell.tsx`（底栏 + 页容器 + 页栈 + 兜底）、`pages/{ChatListPage,ContactsPage,MomentsPage,MePage,ChatPage}.tsx`、`store.ts`（当前 tab / 是否在聊天页）、`shell.module.css`
- 聊天页复用上游 `components/session/SessionView`（它已处理流式/输入/状态栏），顶栏用 `session.header` 槽替换。
- `shell` 壳**不 import 任何其它积木**，页内容全靠槽位。

### 3.3 装配层（L2）

`app/App.tsx` 把现在的 JSX 抽成内部 `ClassicShell`，外面加一行分叉：

```tsx
const layout = useLayout()
return layout === 'wechat'
  ? <Slot name="app.root" payload={{}} fallback={<ClassicShell />} />
  : <ClassicShell />
```

- `app/compose.ts` 的 `compose([...])` 里加 `shell`。
- `components/session/SessionView.tsx` 一行改动：`<MobileHeader title={title} />` → `<Slot name="session.header" payload={{ title }} fallback={<MobileHeader title={title} />} />`。

### 3.4 主题积木（开关放这里）

- `features/theme/catalog.ts`：`ThemeGroup` 加 `'layout'`；新增 `LAYOUTS = [经典, 微信]`。
- `features/theme/store.ts`：`KEYS.layout = 'gaia:theme-layout'`；`apply()` 里调 `setLayout(...)`。
- `features/theme/ui/ThemeMarketPage.tsx`：多渲染一组卡片（"界面"）。
- `theme.module.css`：**不动**（微信壳样式全在 `shell.module.css`，靠 `data-gaia-layout='wechat'` 限定，避免和现有皮肤互相污染）。

## 4. 返回键分级（新增一行，现有不动）

| 优先级 | 处理者 | 变化 |
|---|---|---|
| 75 | 服务商页 | 不动 |
| 70 | 设置页 | 不动 |
| 60 | 角色页 / 主题商城 | 不动 |
| 55 | 记忆面板 | 不动 |
| 50 | 余额页 | 不动 |
| 30 | 搜索面板 | 不动 |
| **25** | **微信壳页栈（聊天页 → 列表）** | **新增** |
| 20 | 移动端抽屉 | 不动（微信壳下不出现抽屉，天然失效） |

> 25 的理由：它必须低于搜索面板（30，聊天页里打开搜索时先关搜索），高于抽屉（20）。

## 5. 视觉规范（照抄微信的取值）

| 项 | 值 | 来源 |
|---|---|---|
| 主色 | `#07C160` | WeUI 官方 token |
| 危险/红点 | `#FA5151` | WeUI 官方 token |
| 页面底 | `#EDEDED` / 深色 `#111111` | WeUI 官方 token |
| 卡片底 | `#FFFFFF` / 深色 `#191919` | WeUI 官方 token |
| 正文/次/辅 | 黑 90%/50%/30% / 白 80%/50%/30% | WeUI 官方 token |
| 我方气泡 | `#95EC69`（黑字） | 社区一致（主题商城已有） |
| 会话行高 / 头像 / 标题 / 副标题 / 时间 | ~64 / 48 圆角 4 / 17 / 14 / 12 | 业界还原值（非官方） |
| 底栏 | 高 54 + 安全区，4 图标 + 文字 10px | 业界还原值（非官方） |

**字体差异要知道**：微信用系统字体（苹方/思源黑），我们打包字体，所以只能"视觉语言像"，做不到像素级。

## 6. 成本影响

- **提示词缓存：零影响**（纯 UI，不碰请求体、不碰 system）。

## 7. 风险与回滚

| 风险 | 处置 |
|---|---|
| 壳崩 = 整屏空白 | `AppShell` 内部 ErrorBoundary → `setLayout('classic')` + toast 一次；`app.root` 槽的 fallback 也是经典壳，双保险 |
| 两套壳样式互相污染 | 微信壳样式全部限定在 `html[data-gaia-layout='wechat']` 下 + 局部 module 类名 |
| 聊天页顶栏重复 | 用 `session.header` 槽 replace，不改 `MobileHeader` 本身 |
| 返回后列表滚动位置丢失 | 页栈里非当前页用 `display:none` 隐藏而不卸载 |
| 通讯录点进错误会话 | 规则固定：`roleIds` 含该角色 且 `updatedAt` 最新；没有则 `setActiveRole` + `newChat` 进入 |
| 切壳后设置页打不开 | 设置仍走现有 overlay（`requestSettings`），与壳无关；验收第 8 条覆盖 |

**回滚**：主题商城切回「经典」；或清掉 `gaia:theme-layout`；或把 `flags.shell` 关掉（`app.root` 无注册 → fallback 经典壳，自动降级）。

## 11. 实施记录（1.8.13-beta.3，2026-11-21 13:40，versionCode 1198）

确认结果：9 项照办；点角色进最近会话；**群聊行不可点（灰显）**；全宽单列。

**已落地**

| 层 | 改动 |
|---|---|
| 平台 | 新增 `platform/layout.ts`（`AppLayout` + `useLayout`/`setLayout`/`currentLayout`）；新增槽位 `app.root` / `shell.contacts` / `shell.me.header` / `shell.me.item` |
| 新积木 | `features/shell`（`flags.shell`，order -200）：`AppShell`（底栏 + 页栈 + `ShellBoundary` 兜底）+ 5 个页面 + `store`（tab / chatOpen）+ `shell.module.css`（WeUI token 配色，含深色） |
| 主题 | `catalog.ts` 加 `LAYOUTS` 与 `ThemeGroup='layout'`；`store.ts` 写 `gaia:theme-layout` 并调 `setLayout`；商城多一组卡片；设置页副标题改「主题 / 气泡 / 背景 / 界面」 |
| 角色 | `roles/ui/ContactsList.tsx`：添加联系人（`openEditor(null)`）→ 群聊（disabled）→ 角色卡；点角色 = `setActiveRole` + 进最近会话 + `runCommand('shell.openChat')` |
| 我页 | profile 注入 `MeCard`（`shell.me.header`）；account/providers/theme/memory/settings×2/diagnostics/intro 各注入一行（`<button data-shell-row>`） |
| 装配 | `App.tsx` 按 `useLayout()` 分叉，微信分支渲染 `app.root` 槽；经典分支整段保留原样（含搜索面板）；兜底按钮可一键回经典 |
| 返回键 | `shell` 注册 25（聊天页 → 列表），其余不变 |

**与方案的差异（要知道）**

1. **聊天页顶栏没用 `session.header` 槽**：槽是全局的，经典壳里也会被 replace，会一起丢掉顶栏。改成给 `SessionView` 加 `bare` 属性（默认 false，行为不变），微信壳传 `bare` 自己画顶栏。
2. **`shell.discover` 槽没做**：朋友圈是纯占位页，不需要注入内容；发现类入口全放「我」页。
3. **群聊行是 `disabled`**：不是"点了给提示"（按你第 3 条改的），也不占返回键。
4. 微信壳会话行**没有"最后一条消息"预览**（`SessionSummary` 里没这个字段），只有标题 + 时间。

**已验证**（真机 Android 16）

- 默认经典，视觉零变化；切微信 → 关掉商城 → 四页壳出现；重启后仍保持；切回经典立即恢复；
- 列表 → 聊天页 → 返回键回列表；通讯录（添加联系人开编辑器 / 点机器人进最近会话）；朋友圈空壳；我页 8 行点开都对；
- 中间包 1197 的通讯录行显示错版问题（CSS 特指度）已修，见功能库 §7.4。

**未验证**：深色模式下微信壳（写了 `body.dark` 覆盖，没实测）；壳抛错自动回退（代码路径在，没人为制造崩溃）；平板/宽屏。
