## 0-0. 返回键分级（1.5.6，真机逐级验证）

原实现里 `MainActivity.onBackPressed` 调的是 `window.__gaiaBack`，但 web 侧从未实现它 → 永远返回 false → 直接 `moveTaskToBack`，所以任何层级按返回都回桌面。现在补了分级返回栈（`platform/back.ts`）：

| 层级 | 返回键行为 | 实测 |
|---|---|---|
| 设置二级页（数据管理/语言/外观/…） | 回到「设置」首页 | ✅ |
| 设置首页 | 关闭设置，回到侧栏（若抽屉开着） | ✅ |
| 角色编辑页 | 回到「管理角色」 | ✅ |
| 角色切换/管理弹层 | 关闭弹层 | ✅ |
| 记忆面板 / 余额页 | 关闭弹层 | ✅ |
| 搜索结果面板 | 收起面板 | ✅ 代码 |
| 移动端抽屉 | 关闭抽屉 | ✅ |
| 以上都没有 | 原生 `moveTaskToBack` → 桌面 | ✅ |

优先级从高到低：设置 70 > 角色 60 > 记忆 55 > 余额 50 > 搜索 30 > 抽屉 20。

## I. 明确未做的（已与需求对齐）

| 项 | 原因 |
|---|---|
| 长按菜单 | 上游已有消息操作行（复制/朗读/分享/重新生成），再叠一套就是双轨，直接不复刻 |

| 群组调度 | 只留口子：`session.kind` / `session.roleIds` / `message.senderRoleId` / `buildPersonaBlocks` |
| 记忆摘要走模型 | M1 用抽取式（零成本零延迟）；换模型摘要只改 `features/memory/summarize.ts` |
