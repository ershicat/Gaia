# 版本历史

版本号规则：正式版 `+0.0.1`（一天最多一次），过程版不动版本名只标 `beta.N`；
版本码只增不减。下面按时间倒序。

完整版（含每版改动的实现细节与踩过的坑）见 [功能库.md §6](功能库.md)。

---

## 1.8.15 — 2026-11-22（正式版）

把 beta.1–beta.6 六件事一起发：会话配角库、角色卡导入导出（含夹带档案/记忆）、
启动失败兜底页、记忆召回降噪 + 原文片段召回、服务商模型列表提示、弹窗遮罩糊影修复。
更新公告整篇重写为五条。

## 1.8.14 — 2026-11-21（正式版）

服务商预设（13 项 + 自定义网关，选好只填 Key）、微信外壳（主题商城 → 界面，四页底栏可切回经典）、
动效 + 透明气泡 + 透明输入框。

## 1.8.13 — 2026-11-20

附件落盘加固。**beta.1 才真修好**：上一版把 `await blob.arrayBuffer()` 写在已打开的 readwrite
事务里，事务被浏览器自动提交，选图发送必定保存失败、会话根本不落盘。改成先转换再开事务、
每个原件各写各的事务。beta.2 加服务商预设协议层，beta.3 加微信外壳，beta.4 加动效与透明气泡。

## 1.8.12 — 2026-11-20

助手回复也进气泡；星夜背景补齐深色文字变量（此前「黑底黑字，啥也看不见」）。

## 1.8.11 — 2026-11-20

主题商城：5 皮肤 / 4 气泡 / 5 背景；`data-gaia-*` + `[data-bubble]` 挂点。

## 1.8.10 — 2026-11-20

有档案卡的长会话跳过抽取式压缩（摘要对角色扮演没帮助，还会每轮作废缓存）。

## 1.8.9 — 2026-11-20
